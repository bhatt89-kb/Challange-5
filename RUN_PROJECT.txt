📋 OPTION 2: MANUAL (STEP BY STEP)
────────────────────────────────────────────────────────────────

STEP 1: INSTALL DEPENDENCIES
------------------------------------------------------------
Open Command Prompt in this folder, then run:

    npm install

Wait 3-5 minutes (be patient!)

STEP 2: SETUP ENVIRONMENT
------------------------------------------------------------
    copy .env.example .env
    notepad .env

Add your API key (get it from: makersuite.google.com/app/apikey)
Change: GEMINI_API_KEY=your_api_key_here
Save and close.

STEP 3: START SERVER
------------------------------------------------------------
    npm run dev

You'll see:
    ✓ Ready in 3.2s
    ○ Local: http://localhost:3000

STEP 4: OPEN BROWSER
------------------------------------------------------------
Go to: http://localhost:3000

Done! 🎉

🐛 TROUBLESHOOTING
────────────────────────────────────────────────────────────────

Problem: npm install hangs
Fix:    npm cache clean --force
        npm install

Problem: 'next' not found
Fix:    rmdir /s /q node_modules
        del package-lock.json
        npm install

Problem: Port 3000 busy
Fix:    set PORT=3001
        npm run dev
